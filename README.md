# ASK 2 GLOBAL Pvt. Ltd. — B2B Procurement & Automation System

An enterprise-grade B2B trade, tender execution, and procurement automation platform built with a high-performance **React (Vite) + Tailwind CSS** frontend and a **Node.js / Express** backend service.
