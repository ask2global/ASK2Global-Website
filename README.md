# ASK 2 GLOBAL Pvt. Ltd. — B2B Procurement & Automation System

An enterprise-grade B2B trade, tender execution, and procurement automation platform built with a high-performance **React (Vite) + Tailwind CSS** frontend and a **Node.js / Express** backend service connected to **MongoDB Atlas**.

---

## 🌐 Live Production Deployment

- **Primary Custom Domain:** [https://www.ask2global.com](https://www.ask2global.com)
- **Apex Domain:** [https://ask2global.com](https://ask2global.com)
- **Vercel Preview Host:** [https://ask2global.vercel.app](https://ask2global.vercel.app)

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** React.js (Vite), Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Hosting & Infrastructure:** Vercel (Serverless Deployments)
- **DNS & Custom Domain Provider:** Hostinger (`ask2global.com`)

---
